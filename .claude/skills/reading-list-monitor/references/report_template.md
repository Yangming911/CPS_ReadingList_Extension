# 调研报告模板

本文档定义了 reading list 新论文调研报告的写作规范。

## 语言规范

- **正文语言：中文**
- **学术专有名词保留英文原文**，例如：barrier certificate、reachability analysis、signal temporal logic、model checking、reinforcement learning、Lyapunov function 等
- 首次出现的英文术语可以附带中文解释，例如："该方法基于 control barrier certificate（控制障碍证书），用于..."
- 论文标题保留英文原文
- 作者姓名保留原文
- 数学公式和变量名使用英文/LaTeX 格式

## 模板结构

```markdown
# [论文英文原标题] — 调研报告

> 生成日期：YYYY-MM-DD | Reading List Monitor
> 论文来源：[arxiv/会议链接（如有）]

## 1. 问题背景与研究动机

清晰阐述这篇论文要解决的核心问题。为什么这个问题值得关注？
现有方法存在哪些不足？本文的核心贡献是什么？

写作要求：
- 假设读者有 CPS/控制/形式化方法方向的研究生水平背景
- 具体说明技术挑战，而非泛泛而谈
- 用 1-2 段话让读者理解"这篇文章在做什么、为什么值得读"

## 2. 技术方法

描述论文提出的方法论框架：
- 核心算法或技术路线
- 关键理论贡献（如有）
- 计算方法（optimization、learning、verification 等）
- 重要假设和约束条件

写作要求：
- 让读者理解方法的"轮廓"，无需阅读原文即可把握技术思路
- 适当使用数学符号辅助说明，但不要堆砌公式

## 3. 研究前沿与意义

将本文放在更广泛的研究背景下讨论：
- 这是否是一个快速增长的研究方向？证据是什么？
- 主要竞争方法有哪些？
- 哪些研究组/实验室在此领域活跃？
- 主要发表 venue（会议/期刊）有哪些？

## 4. 相关工作（3-5 篇）

每篇相关论文需包含：

### [论文标题]
- **作者**：（如能找到）
- **发表信息**：venue/年份
- **关联分析**：与本文的关系——解决类似问题？方法互补？
- **关键区别**：在方法、假设、适用范围上有何不同？

## 5. 组会讨论要点

2-3 个适合研究组会讨论的问题：
- 开放问题或方法局限性
- 与本组研究方向的潜在联系
- 可能的后续工作或扩展方向

## 参考文献

[1] 完整引用格式，附链接
[2] ...
```

## 写作风格指南

- **学术严谨**：面向研究组的调研综述，不是科普文章
- **避免空泛赞美**：不写"开创性的""突破性的"，改为具体说明创新点在哪里
- **不确定时要诚实**：如果只找到标题和摘要，明确说明"根据论文标题和摘要推断..."
- **术语使用精准**：使用 CPS/控制/形式化方法领域的标准术语
- **篇幅适中**：每份报告 1500-2500 字左右，确保有深度但不冗余
